01 — HOW IT WORKS

One focused repro.
Everything it needs.

01

Start a capture

Record a browser tab, selected desktop app, iOS Simulator, or Android Emulator.

02

Reproduce the issue

Patchmason follows the evidence: steps, errors, logs, requests, screenshots, and optional app video.

03

Review and hand off

Remove anything private, add expected behavior, then export Markdown or JSON for your agent or teammate.

04 — PATCHMASON CLOUD

Production context.
Only when it helps.

Core stays local and open source. Patchmason Cloud is the opt-in workspace for teams that need a secure path from a customer report to the context that fixes it.

DEBUG CONTEXT PACKREVIEWED ✓

01ReportExpected and actual behavior, verified by the reporter.

02EvidenceRelevant logs, errors, app version, device and session correlation.

03ControlsAllowlisted fields, redaction, consent and workspace access rules.

Never raw account access. Never silent collection.
EXPLICIT

The reporter chooses what leaves the device.

A report is reviewed before it is shared. Teams can request context; they cannot quietly extract it.

MINIMIZED

Debug fields are allowlisted, sensitive fields are redacted.

Tokens, credentials, payments and unrestricted free text stay out by default. Retention is set per workspace.

USEFUL

One incident, one searchable trail to a fix.

Connect production context to the issue tracker, owner and release where the regression gets resolved.

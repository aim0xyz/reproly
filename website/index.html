01 — HOW IT WORKS

One focused repro.
Everything it needs.

01

Start a capture

Record a browser tab, selected desktop app, iOS Simulator, or Android Emulator.

02

Reproduce the issue

BugDrop follows the evidence: steps, errors, logs, requests, screenshots, and optional app video.

03

Review and hand off

Remove anything private, add expected behavior, then export Markdown or JSON for your agent or teammate.
